Google account

Linking a Google account enables your subscriptions and their recent uploads. Create an OAuth client of type TV and Limited Input in a Google Cloud project with the YouTube Data API v3 enabled — a Web or Desktop client will be rejected by the device flow.

Cookies

Required for playback and the Recommended feed: YouTube only serves a personalised home feed to a signed-in session, and the Data API has never exposed the recommender. Export a cookies.txt in Netscape format from a browser signed in to your account and paste it below. Cookies also let age-restricted videos resolve.

These cookies grant access to your Google account. They are stored in Emby's plugin configuration and written to the plugin data folder on this server.

Saved searches

Emby 4.9 ignores the old searchable-channel interface, so the client's search box cannot query YouTube live. Each saved search below becomes a folder in the channel; opening it runs a real search.

Playback

Above 720p YouTube serves video and audio as separate streams, and an Emby media source carries exactly one URL — so the plugin selects the best single file that already contains both. In practice that caps playback at 720p.

yt-dlp

The Emby container ships neither yt-dlp nor Python, so the plugin manages its own self-contained copy in the plugin data folder. Keep it updated — a stale build is the usual reason playback stops working.
